# Suivi des temps de Luka

Site de suivi des performances de natation de Luka : records, progression, qualification aux départementaux, webconfrontation et historique.

- `index.html` : le site. Pas besoin d'y toucher.
- `donnees.js` : les temps saisis à la main et les réglages (grille des départementaux, webconfrontation).
- `donnees-ffn.js` : courses récupérées automatiquement sur la fiche FFN de Luka. Ne pas le modifier.

## Mettre à jour depuis la FFN

Onglet **Actions** > « Mise à jour depuis la FFN » > **Run workflow** (ou bouton « Mettre à jour le site de Luka » sur le site de suivi).
